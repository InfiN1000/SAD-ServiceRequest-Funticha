# Requirements Traceability Matrix

- FR-01: User can log in — Implemented in login.html and js/supabase.js (TC-01)
- FR-02: User can create request — Implemented in index.html form and js/app.js insert (TC-02)
- FR-03: User can view requests — Implemented in index.html table and js/app.js fetch (TC-03)
- FR-04: User can update request — Implemented in index.html edit form and js/app.js update (TC-04)
- FR-05: User can delete request — Implemented in index.html delete button and js/app.js delete (TC-05)
- FR-06: User can search — Implemented in index.html search input and js/app.js search (TC-06)
- FR-07: User can filter — Implemented in index.html filters and js/app.js filter (TC-07)
- FR-08: Dashboard summaries — Implemented in index.html dashboard and js/app.js counts (TC-08)
